# c0ns1d2 · 记忆库

个人记忆网站。保留开场与记忆卡片，以照片、文字和手动关联的想法串起记忆。

## 日常使用

双击项目里的 `启动.bat`，等待构建后打开 [本地后台](http://127.0.0.1:4323/admin)。启动窗口关闭后服务继续运行；重复启动会复用本项目服务。若页面提示断线，再次启动后点「重新连接」，无需刷新当前输入。

后台只有三个内容入口：

- **记忆**：填名称与时间，放照片，写下经过或感受，点「保存记忆」。
- **作品**：记一本书、一部电影或一个游戏。只填名字与类型也可以，资料和感受都可后补。
- **想法**：直接写，不必先选事件。浏览记忆或作品时，也可在「从这里想到的」里记录；写过的内容统一在「想法」中查找。

默认仅在本地后台保留。需要前台显示时勾选公开；保存后自动更新本地预览，不等于推送或部署线上网站。Ctrl/Cmd+S 保存当前表单。

## 记忆层次

保留原有大、中、小事件整理方式：

- **大事件**：在「分层整理与参与人」勾选，公开后展示在首页记忆卡片。
- **中事件**：左侧「中事件 · 分组整理」管理分组，支持嵌套。事件编辑区可选择归入哪一组。
- **小事件**：普通记录，可以归入中事件，仍可单独浏览。

不再另设核心、聚餐、考试等固定分类操作；旧分类和标签数据兼容保留，独立分类与统计页面已退出使用。前台「记忆」内切换列表与绳子时间线。人物资料从事件里的参与人进入。

## 绳子时间线

选年份，必要时再用原有中事件分组筛选；父分组包含子分组中的记忆。桌面横向滚动，也可用上方左右箭头翻阅；手机按纵向阅读。点卡片进入详情，返回后恢复筛选和阅读位置。「最近一件」跳到当前范围的最近记录。

浅绳将日期挂到卡片，红绳连接相邻事件。明确的先后用实线，同日或模糊日期用虚线；这是时间排列，不是自动生成的联想。间隔只服务阅读，不代表实际相隔天数。只有年份、月份的日期保留原精度；未知日期收在「日期未定」。首页原有开场与记忆卡片保持原样。

时间线分为内容模型（timeline-model.mjs）、静态卡片模板、独立样式及测量式绳子绘制（timeline-threads.mjs）。滚动由浏览器处理，只有筛选或尺寸改变才更新几何，不再使用旧无限画布的缩放、分道和文件夹条。

## 写文字与导入照片

- 平时写在「记下这件事」即可。「自定义列表介绍」可不填，列表和时间线自动取正文开头；填写后替代自动预览。
- 旧记录若只有摘要、没有正文，后台会把已有文字显示在主编辑区，用户保存时再统一到正文，不批量改原文件。
- 照片区点「＋」或拖入多张照片，支持 JPG、PNG、GIF、WebP、AVIF，单张不超过 10MB；上传后还需保存记忆。
- 第一张照片用作列表、时间线和首页卡片封面，全部照片在详情里可放大查看。照片上的「×」只移除引用。
- 想法的标题、关联条目和摘录都可后补。旧随笔也在同一个「想法」入口阅读。
- 有关联的想法，想法本身和填写的关联端点都公开后才会展示；独立想法可单独公开。
- `public/` 下的媒体会直接发布，不应用来存放尚未允许公开的附件。

## 清理记录

来源筛选可只看「自动生成的事件」。点「多选」逐条查看并勾选，或全选当前搜索结果；切换搜索保留选择，总数可见。移入回收站前核对标题、日期、公开状态和照片数。

回收站支持单条或批量恢复，原文、图片引用和公开/精选状态一并还原。有关联想的事件暂阻止移除，恢复也不会覆盖同名记录。回收站位于本机 `.local-trash/events/`，不进入网站或 Git；照片文件不随事件删除。

## 项目与验证

Astro 静态网站，Node 本地编辑服务；内容保存在 `src/content/`，编辑后台在 `admin/`。

```text
npm install
npm run dev           # 前台开发
npm run build         # 构建并核验公开范围
npm run test:associations
npm run test:trash
npm run test:intro
npm run test:timeline
npm run check:timeline # 时间线专项：隔离副本中的桌面、手机与边界场景
npm run check:editor  # 隔离副本中的浏览器回归，不写正式记录
npm run check:intro   # 真实开场检查，需要本地后台运行
```

`agent-memory/`、`data-tools/`、`.local-trash/` 与环境配置仅在本机保存。旧分类、统计和随笔目录地址保留跳转，既有事件、人物、作品和想法的地址继续可用。
