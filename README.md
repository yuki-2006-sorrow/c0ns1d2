# c0ns1d2 · 记忆库

以共同创作为中心的作品档案：创作者浏览素材、产生灵感，通过剪辑台编排图文与音视频作品；访客阅读已发布成品。

开发接手请先阅读 [项目交接（2026-11-01）](docs/项目交接-2026-11-01.md)，其中汇总产品决策、代码地图、预览方式、验证记录和待办。

首页保留原开场视频与三段点击节奏，可跳过；看过后直接进入作品展厅，页脚可重看。素材与创作页面直接进入。当前部署接入与验证见[本轮发布记录](docs/发布记录-2026-11-01.md)。

## 日常使用

- 双击「启动.bat」：启动统一后台，并在已配置固定通道时打开 https://c0ns1d2.com/ 。
- 访客从首页作品展厅阅读成品；具有创作者权限的账号可以进入素材库、剪辑台和作品草稿。
- 双击「关闭网站.bat」：关闭本项目的公网连接和本机后台，保留资料。

电脑和网络需要保持运行。已有授权和固定地址不必重复申请；原 https://c0ns1d2.pages.dev/ 继续可用。尚未配置公网时，启动器打开本机站点。首次在本机建立站主账号，之后沿用已有账号。

## 只有一份正在编辑的资料

网站和后台共用 `.local-collaboration/archive.json`。记忆、作品、想法、人物侧写、中事件分组、账号与分享权限均由统一后台管理，保存后按访问者权限立即显示，不必构建或 push 内容。

旧 `src/content/` 保留供迁移恢复和前端模板构建，退出日常编辑流程；不会与正在使用的资料相互覆盖。原始资料编辑器在发现已有统一资料库时拒绝启动，旧本机启动脚本也进入统一后台。

旧版资料库首次升级时会在 `.local-collaboration/backups/` 保存逐字节相同的旧库，再迁入人物、分组和原话片段。保留既有记忆正文、ID、版本、作者、账号、准入题目与权限。原来没有进入共享库的记录应先核对再迁入，不能以旧文件覆盖网站内已改内容。

## 写作和整理

- **作品展厅**：首页仅展示已发布成品。原始小事件不会自动变成作品或直接向访客开放。
- **素材库**：仅创作者可进入，沿用原始资料的分享范围。聊天导入、小事件、照片、视频、音频、随笔和想法均为可引用素材。旧 ID、原文、来源和版本继续保留。
- **剪辑台**：从素材选择开始，调整引用文字、片段顺序和说明，添加串联文字或音视频，保存为独立作品草稿。
- **共同创作**：发起人邀请其他创作者，保存时校验版本避免覆盖；修改记录、历史版本和讨论归属真实账号。当前采用保存与重新载入，尚非实时多人光标编辑。
- **成品发布**：发起人或站主发布独立快照。修改草稿不改变已发布版本，撤回成品会关闭作品和作品媒体地址。
- **资料整理**：原分组、时间线、人物和可恢复回收站继续作为创作者整理素材的工具。

素材作者保留自己的原文。作品中的引用可以单独编排，访客只看到作品采用的片段，不得到完整素材、来源路径或内部讨论。新架构与美术参考见[作品与素材架构](docs/作品与素材架构.md)。

## 备份与部署

「导出文字资料」不含照片视频和账号凭据。完整备份请先关闭网站，再将 `.local-collaboration/`、`public/photos/` 以及项目一起复制到另一块磁盘；有效通道凭据也在私有目录，不能上传公开仓库。原事件回收站 `.local-trash/` 继续保留作迁移恢复，日常使用统一后台的回收站。

网站代码和界面更新仍通过 GitHub / Pages 发布；内容和权限更新由当前电脑直接提供。固定域名、迁移主机和高级维护见[固定域名接入](docs/固定域名接入.md)。腾讯云媒体服务尚未接入。

## 开发验证

```text
npm install
npm run dev                  # 前端模板开发
npm run build                # 构建并核验公开范围
npm run admin                # 统一后台（本机4324）
npm run test:collaboration    # 迁移、权限、共享前台和整理功能
npm run test:intro
npm run test:timeline
node --test scripts/remote-entry.test.mjs
```

原始文件编辑器及旧测试工具仅供恢复/隔离测试使用，不能继续维护第二份在线资料。`.local-collaboration/`、`agent-memory/`、照片原片与环境配置均不提交公开仓库。
