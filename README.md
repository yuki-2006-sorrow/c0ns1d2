# c0ns1d2 · 我的生活

私人生活记录与计划工具，仅本人站主账号可用。

- 今天：每日任务、完成与改期、日常记录。
- 计划：项目进度、下一步、关键日期、DeepSeek 任务拆解。
- 记录：日常、每周回顾和 Siri 随手想法。
- 我：个人方向、iPhone 凭证、DeepSeek 设置与账号。
- 自动导入：来源状态、文件读取结果、资料与项目的关联；从今天页进入。

AI 拆解发送选定项目、补充说明，以及本人勾选的个人背景与相关可用资源；发送前可展开预览。生成后可修改、选择并安排日期。“我”页面支持时间、能力与限制，以及可关联项目的资源清单。API Key 在“我 → AI 管家”填写，仅服务端保存到被 Git 忽略的 .local-collaboration/ai-config.json，也支持 DEEPSEEK_API_KEY 环境变量。不会自动向 AI 发送其他项目详情、日记或凭证。

原共同创作、作品发布、素材库、邀请注册和相关接口已退出运行网站。旧链接跳转个人空间，旧内容接口返回410。历史备份保留，不重新导入。

## 使用与运行

双击“启动.bat”启动当前电脑后台和既有 Cloudflare 通道。正式入口 https://c0ns1d2.com/personal 。电脑与网络需保持在线。默认后台端口4324；4327为隔离预览，不保存正式密钥。

私人资料位于 .local-collaboration/archive.json。备份时先停止后台，复制整个 .local-collaboration/；密钥配置不进入 Git、公开构建或文字导出。原素材备份位于 .material-backups/。

历史协作测试与文档仅供旧版本追溯。当前功能见 docs/项目进度与每日计划-2026-11-02.md 和 docs/iPhone与Siri记录-2026-11-02.md。

## 自动导入

后台在线时，每60秒检查 `.local-collaboration/自动导入/`。新增或修改的 PDF、DOCX、PPTX、UTF-8 TXT/MD 会提取文字；教务课表 XLSX 会更新同学期快照。只读源文件，不移动、不删除。文件上限15MB，课表512KB，最多保留200份文字资料；扫描件尚不支持OCR。每份资料最多保存64000字，AI每次最多参考5份、每份4000字，可在发送前预览，或在导入页关闭参考、关联项目。

可选私有配置 `.local-collaboration/import-sources.json`：`{"schoolNotices":true,"studentNotices":true,"sources":[]}`。`sources` 仅由本机配置，支持 `{id,name,kind:"file"|"folder",path}`；不会扫描整个手机或下载目录。开启对应来源后，每小时读取浙大综合服务网和学工部官网首页通知的标题、发布日期和原文链接，以关键词筛选；失败保留旧信息并每5分钟重试。手动检查可立即重新获取。后台同步不调用AI，不自动报名、不自动创建任务。

课程云端资料、ETA个人信息、浙大钉、学在浙大、微信公众号仍需要独立连接；本机目录监测不等于课程平台同步。网站会显示失败、缺失来源与上次成功时间。原文件失效时保留已导入文字并标记过期，过期资料不送给AI；课表保留为带导入时间的快照。电脑睡眠、关机或后台停止时不会同步。每次有新数据写入前，自动备份现有个人数据到被Git忽略的备份目录。
