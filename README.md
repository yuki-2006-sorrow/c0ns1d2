# c0ns1d2 · 共同留下

共同书写和发布帖子的创作空间。帖子支持图文混排和音视频，创作者选取素材、编排片段、撰写文字并邀请共同创作；访客阅读已发布帖子。

## 当前状态（2026-11-01）

用户决定将历史素材全部备份并移出网站。541 条旧素材、原人物资料、分组、旧内容源与预览副本已备份到本机 .material-backups/，576 个文件逐一通过 SHA-256 校验。网站素材库现为空，不自动导入旧内容。6 个账号和原有准入设置保留。

旧 src/content/ 内容已移出，仅保留集合配置和空目录占位。历史资料不再随网站构建或 push，私人备份不进入公开仓库。操作说明见[素材移出记录](docs/素材移出记录-2026-11-01.md)。更早的交接文档是历史状态，以上述决定为准。

## 日常使用

- 双击“启动.bat”启动后台与已配置的固定通道，正式入口 https://c0ns1d2.com/ 。
- 创作者进入“创作台”新建帖子，可以直接写文字，也可以收录新素材后引用。
- 保存草稿后，受邀创作者可共同编排；保存会检查版本，尚非实时多人编辑。
- 发起人或站主发布独立快照，访客才可阅读。继续修改草稿不改变已发布版本。
- 首页保留原开场视频，可跳过，看过后直接进入帖子列表，页脚可重看。其他页面不插播。
- 双击“关闭网站.bat”停止公网连接和后台，资料保留。

内容、账号及权限共用 .local-collaboration/archive.json。素材库仅供创作者按分享范围使用，修改引用不改原素材。电脑和网络需保持运行。

## 备份与部署

完整备份应先关闭网站，复制 .local-collaboration/、public/photos/ 与项目；仅导出文字不包含全部媒体与账号。.local-collaboration/、.material-backups/、环境配置和原片不能提交公开仓库。恢复历史素材前先另备份当前资料，避免覆盖新帖子。

代码与界面通过 GitHub / Pages 发布，内容由当前电脑提供。固定域名与通道维护见[固定域名接入](docs/固定域名接入.md)。
