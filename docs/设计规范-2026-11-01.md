# c0ns1d2 设计规范（美术与控制台）· 2026-11-01

> 目标：把"覆盖层 + 旧主题残留"重做为一套干净、单一、可维护的设计系统。
> 参考来源见文末附录。所有令牌集中在 `minimal-system.css` 的 `:root`，页面 CSS 只写布局。

---

## 一、设计原则

1. **内容自己承载设计**（Are.na）：不做装饰性元素，层级靠字重、留白、细线，不靠颜色、投影、渐变。
2. **每个容器最多 3 项**（Linear "3 项规则"）：超出的动作折进"更多"或上下文面板，降低认知负载。
3. **稳定面 + 易变面分层**（Linear 桌面+白纸）：全局导航固定不动，剪辑/预览等易变内容作为浮层或卡片。
4. **减法优先**（Kinfolk）：留白占 40–60%，权威来自间距和字重，不是尺寸和颜色。
5. **无投影**：深度只通过"边框粗细 + 背景色阶"表达，全局 `box-shadow:none`。
6. **中性、无彩色**：去掉现有浅绿/深绿/红，强调色就是炭黑本身。

## 二、设计令牌（Design Tokens）

### 2.1 色板（纯中性，9 个 token）

| 令牌 | HEX | 用途 |
|---|---|---|
| `--bg` | `#fafaf9` | 页面主背景（近白） |
| `--surface` | `#ffffff` | 卡片/纸张/输入框底（纯白） |
| `--surface-alt` | `#f4f4f2` | 次级容器、轨道、分区底 |
| `--line` | `#e3e3e0` | 1px 细线、分隔线、默认边框 |
| `--line-strong` | `#c9c9c5` | 更强的边框、hover 边框 |
| `--ink` | `#1d1d1b` | 主文字、主按钮底（炭黑） |
| `--text` | `#3a3a37` | 正文文字 |
| `--muted` | `#6f6f6a` | 次要文字、元信息 |
| `--faint` | `#9b9b95` | 弱化标签、占位、禁用前提示 |

**关键规则**
- 无任何彩色强调。链接/选中/主按钮统一用 `--ink`。
- 现有 `#e8ebe2`、`#42483d`、`#f0f2eb`、`#9ea594`、`#555e4d` 等偏绿值全部废弃。
- 警示/错误（如发布校验失败）不引入新色：用 `--ink` 文字 + 左侧 2px `--ink` 竖线表达；危险操作（移出/删除）文字用 `--muted`，hover 时才变 `--ink`。
- 禁用态：`opacity:.4`，不另设颜色。

### 2.2 字体

**单一字体栈（无衬线，不引入衬线/等宽外部字体，零网络字体依赖）**
```css
--font: -apple-system, BlinkMacSystemFont, "Segoe UI",
         "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei",
         "Helvetica Neue", Arial, sans-serif;
```
- 底层残留的 Georgia / Songti / Times 衬线全部删除，`--serif` 别名移除。
- 中文**不使用负字距**：现有 `letter-spacing:-1.5px/-1px/-0.5px` 全部改为 `letter-spacing:0`（西文标题如需收紧，最多 -0.01em，且仅作用于西文）。

### 2.3 字号与字重层级

| 层级 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| display | `clamp(30px, 5vw, 44px)` | 1.25 | 500 | 页面大标题（不再用 60–112px 巨型） |
| title | `clamp(22px, 3vw, 28px)` | 1.35 | 500 | 卡片/区块标题、剪辑台作品名 |
| heading | 17px | 1.5 | 500 | 小节标题 |
| body | 15px | 1.8 | 400 | 正文（中文屏幕建议 15–16px） |
| small | 13px | 1.7 | 400 | 辅助正文 |
| label | 11px | 1.4 | 500 | 标签/元信息/按钮（大写西文时字距 0.08em） |

- 中文正文行高 1.7–1.8（中文填满字框，需比西文更大行距）。
- 阅读页正文行宽限制 **28–35 个中文字符**（约 `max-width:34em`），西文 45–70 字符。
- 字重只用 400 / 500 两档，不用 600+。

### 2.4 间距（8pt 基准）

```css
--space-1:4px; --space-2:8px; --space-3:12px; --space-4:16px;
--space-5:24px; --space-6:32px; --space-7:48px; --space-8:64px; --space-9:96px;
```
- 所有 padding/margin/gap 取令牌值，不写零散像素。
- 页面左右边距：桌面 `5vw`（不小于 24px），移动 `20px`。
- 章节之间用 `--space-8/9`，容器内部用 `--space-4/5`。

### 2.5 圆角、边框、阴影、动效

- 圆角：`--radius:2px`（按钮/输入/卡片统一 2px，接近直角；不混用 3/6/8px）。
- 边框：统一 `1px solid var(--line)`；激活/选中用 `1px solid var(--ink)`，不用加粗以外的手段。
- 阴影：`--shadow:none`，全局无投影。
- 动效：`--transition:150ms ease`，仅用于颜色/边框/透明度；位移用 `200ms ease`。
  - 禁止弹跳、闪烁、大幅缩放；`prefers-reduced-motion` 时全部禁用。
- 焦点：`:focus-visible { outline:1.5px solid var(--ink); outline-offset:2px }`，无发光（现有 `#555e4d` 改 `--ink`）。

## 三、布局网格与断点

- 统一断点（替换现有 600/650/760/1050 多套）：
  - `≤640px`：移动端，单列。
  - `641–1024px`：平板，窄双列。
  - `>1024px`：桌面，完整多列。
- 网格基于隐形对齐，不显示网格线；内容可非对称，但边缘对齐到同一基线。
- 作品卡片网格：桌面 2 列（`gap:48px 32px`），移动 1 列；取消"第 3n 跨列居中"这类特殊规则。

## 四、组件规范（统一类名，写进 minimal-system.css）

### 4.1 按钮（三级，不再靠颜色区分）
| 类 | 样式 | 用途 |
|---|---|---|
| `.btn-primary` | `background:var(--ink);color:var(--surface);border:1px solid var(--ink)` | 唯一主动作（发布/确认） |
| `.btn` | `background:transparent;border:1px solid var(--line);color:var(--text)` | 次要动作（保存/预览/邀请） |
| `.btn-ghost` | 无边框、`color:var(--muted)`，hover 变 `--ink` | 弱动作（取消/文字链接） |
- 统一高度 40px（移动最小点击区 44px），padding `0 18px`，`border-radius:var(--radius)`。
- hover：`.btn-primary` 背景从炭黑变为 `--text`（仅明度微调，不变绿）；`.btn` 边框变 `--line-strong`。
- 同一工具条内按钮最多 3 个，超出收进"更多"下拉。

### 4.2 卡片 `.card`
- `background:var(--surface);border:1px solid var(--line);padding:var(--space-5)`，无阴影。
- 选中态：`border-color:var(--ink)`（不换浅绿底）；hover 未选中：`border-color:var(--line-strong)`。
- 作品封面：占位底用 `--surface-alt`（不用浅绿），标题水平排列在封面下方或左下，不用垂直标题。

### 4.3 输入 `.input` / 文本域 `.textarea`
- `background:var(--surface);border:1px solid var(--line);padding:11px 14px`，圆角 2px。
- focus：`border-color:var(--ink)`，无 glow；placeholder 用 `--faint`。
- 复选框：`accent-color:var(--ink)`。

### 4.4 导航 `.site-nav`
- 固定/sticky 顶部，`background:var(--bg);border-bottom:1px solid var(--line)`。
- 品牌名统一后缀（二选一，建议统一为"共同留下"，删除"共同创作档案/COLLECTIVE ARCHIVE"）。
- 导航项 ≤4 个：作品展厅 / 素材库 / 草稿 / 账号；当前页用 1px 下划线表示，不用高亮色。
- 修复 `/shared` 黑块：所有下拉菜单 `background:var(--surface);color:var(--text)`。

### 4.5 标签 `.label`、Toast `.toast`
- 标签：11px、`--muted`、西文大写 `letter-spacing:.08em`，不使用彩色。
- Toast：固定底部居中（不是右下），`background:var(--ink);color:var(--surface);padding:12px 20px`，3 秒自动消失，无阴影；统一所有提示走这一个组件。

## 五、素材库交互规范

1. **统一布局，取消移动横向滚动**：移动端与桌面都用**垂直网格**（移动单列/平板双列），不再用横向卡片+横向滚动条，保证可发现性。
2. 每张素材卡：缩略图 + 类型标签 + 标题 + 摘要（5 行截断）+ 右上角复选框；选中 = `border-color:var(--ink)`。
3. 顶部控制条：搜索框（占主要宽度）+ 类型筛选 + 主动作"用所选素材创作"（`.btn-primary`），控制条元素 ≤3。
4. 空结果/无素材：居中 `.empty-state`，一句说明 + 一个引导按钮，不显示空白网格。
5. 素材原内容只读：加入作品时明确提示"素材原文保持不变"（沿用现有正确文案）。

## 六、剪辑台信息架构（重点修正）

### 6.1 动作主次重排（解决三按钮权重混乱）
按"草稿（静默）→ 预览 → 发布（强确认）"的真实流程重排：
1. **保存草稿**：改为 `.btn`（次要），并实现**自动静默保存**（编辑后自动保存，显示"已保存于 HH:MM"小字），不再用黑底主按钮。
2. **预览**：`.btn`，打开/切换阅读态预览。
3. **发布成品**：唯一 `.btn-primary`，点击后弹出确认层（显示标题/可见范围/片段数），二次确认才发布。
4. **协作记录/邀请**：折进右上角"更多"或 `.btn-ghost`，不与主流程抢视觉。
- 顶部主动作保持 ≤3 个。

### 6.2 布局：桌面+白纸分层，移动减少滚动
- **桌面（>1024px）三栏**：
  - 左：素材库（固定、可搜索，"桌面"稳定面）。
  - 中：作品纸张预览（"白纸"，随编辑实时更新）。
  - 右：片段检查器（上下文面板，随选中片段切换；不做第二个永久侧边栏）。
- **移动（≤640px）用分段切换代替长滚动堆叠**：
  - 顶部三个分段标签：素材 / 编排 / 预览（默认在"编排"）。
  - 一次只显示一个面板，避免在素材、轨道、预览之间来回滚动对照。
  - 片段编辑用底部滑出 sheet（`position:fixed;bottom:0`），编辑完收起即回到预览。
- 平板（641–1024）：素材折叠为可召唤抽屉，主区为预览+轨道。

### 6.3 片段的单一事实来源 + 强同步
- 数据层片段是唯一来源；画布、轨道、检查器只是它的三种视图。
- 选中片段时三处**同步高亮**：统一 `border-color:var(--ink)` + 左侧 2px `--ink` 竖线，替换现有浅绿选中态。
- 块操作（前移/后移/移出）放在检查器和片段卡的"更多"菜单里，不铺满一排按钮。
- 参考编辑器范式：片段卡左侧加拖拽手柄（块菜单），拖拽不抢焦点；未来可加 `/` 插入菜单（斜杠命令），本期可先不做。

### 6.4 协作语义（避免误导为实时）
- 明确文案：协作是"保存 + 重载 + revision 冲突检查"，非实时。
- 不展示实时光标/在线头像动画；冲突时弹"对方已有新版本，请先重载"面板，给出 重载/另存副本 两个选择。
- 邀请、下载副本、创作记录、留建议统一收进协作面板（右侧滑入），样式复用 `.card/.btn`。

## 七、空 / 错误 / 加载状态（补全）

| 状态 | 呈现 |
|---|---|
| 空列表 | `.empty-state`：一行 `--muted` 说明 + 一个 `.btn-primary` 引导动作 |
| 加载中 | 用 1px `--line` 骨架占位（`--surface-alt` 块），不转圈花屏 |
| 加载失败 | 说明文字 + "重试"按钮，不静默吞错 |
| 表单校验 | 字段下方 `--muted` 小字 + 字段边框 `--ink`；不引入红色 |
| 冲突/危险确认 | 居中确认层，明确后果，主按钮文案写清动作（如"确认移出"） |

## 八、落地改造顺序（任务 #35 参考）

1. 重写 `minimal-system.css`：`@layer` 化（tokens → base → components），落地第二、四节令牌与组件类，删除所有 `html body` 高特异性覆盖。
2. 清理 4 个页面 CSS：删除深色 `:root`、衬线、红色印章、浅绿等全部被覆盖的旧主题，只保留各自布局。
3. 统一导航/品牌/断点/Toast；修复 `/shared` 黑块。
4. 改造素材库为统一垂直网格。
5. 重排剪辑台动作主次与响应式布局，补自动保存与发布确认。
6. 补空/错误/加载态；`npm run build` 验证，4327 预览逐页回归。
