# 旧模板浅色遗漏修复 · 2026-11-01

真实体验发现部分创作者整理页面仍为深色。根因是 `src/styles/archive.css`、`BaseLayout.astro` 与 `src/styles/timeline.css` 未完成主题迁移；单独清理管理端 CSS 无法覆盖这些模板。另有旧全局 reset 未分层，会覆盖新版组件留白。

已在源文件修正：

- 档案模板导入共享设计系统，旧变量改为共享令牌别名；阅读正文、引文、按钮与链接同步改为浅色配套颜色。
- 公共模板导航改浅色，移除会覆盖组件间距的全局 reset。
- 时间线移除深色渐变、厚重投影和深色原生下拉框；使用中性色阶。
- 网关离线提示页改为浅色。
- 修正照片查看器关闭时被 `display:flex` 强制显示的问题；仅在真正打开媒体时显示深色全屏查看区。

验证：构建及公开范围检查通过；时间线 8 项、前台与网关 16 项测试通过。浏览器检查专题、时间线、原始记录阅读页、人物页；实际 body 背景为 `rgb(250,250,249)`，阅读正文为 `rgb(58,58,55)`，未打开的照片查看器为 `display:none`。

本次没有修改资料内容、账号或分享权限。开场影像与媒体查看区保留观看用深色背景。
