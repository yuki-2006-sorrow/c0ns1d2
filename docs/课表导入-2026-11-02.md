# 教务课表 Excel 导入

入口：“我 → 课程与课表”。仅站主可预览与导入，手机写入凭证不能调用。支持教务系统导出的课程列表xlsx，第一张表含学年学期标题及课程代码、课程名称、教师、学期、上课时间、地点列。上传文件最大512KB，解压读取限定XML文件与大小，禁止DOCTYPE/ENTITY。

按课程代码合并同课程行，按学期、周几、节次和地点去重上课安排。保留原始行以供追溯。标题中的姓名与源文件名不进入课表数据。同一学年学期按 sourceKey 更新快照，相同文件哈希重复导入不创建新记录。服务器导入前备份当前资料库，不修改其他个人信息、项目、资源或手机凭证。

AI“参考我的个人背景与课表”启用时包含课表中的课程及学期/周几/节次，不包含教师、教室、原始行和原文件。源表缺少教学周、具体日期、钟点时，必须保留限制，不能计算准确空闲时间或认定今天有课。选课时间不作为上课日期。

当前导入的是文件快照，不是学校实时连接。后续可以重新导出同一格式并在页面上传更新。自动登录学校与定时同步仍未接入。课程教材、课件的内容不在课表中，尚未导入。

测试使用虚构工作簿，验证合并、去重、同学期更新、异常文件、AI上下文与权限。用户文件只存本机被Git忽略的私人资料目录；不会随源码发布。
