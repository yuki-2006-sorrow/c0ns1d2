# 历史素材备份与移出 · 2026-11-01

用户确认网站以共同书写的帖子为中心，并要求先备份、再将现有素材全部移出网站。本记录更新此前“保留旧素材在线使用”的交接状态。

## 执行范围

- 停止后台和隔离预览写入后，备份当前完整资料 JSON、旧内容集合、媒体目录、回收站与两个素材预览副本。
- 576 个文件逐一校验 SHA-256，清单保存为 manifest.json，恢复方法保存为“恢复说明.txt”。
- 备份位于项目根目录 .material-backups/，不在 Web 目录内，并已加入 Git 忽略。
- 移出 541 条历史素材、13 个原分组和 17 份人物资料，同时移除相关素材历史与已退役素材的操作详情；账号、密码校验记录、准入配置与权限保留。
- 当前资料库没有帖子和上传媒体，因此本次保留 6 个账号、0 篇帖子，没有删除任何帖子。
- 旧 src/content/ 各集合只保留空目录占位。旧源文件和原预览副本已移入私人备份，避免再次自动导入或继续显示在预览中。
- 清理并重新生成 dist/ 与 .astro/，公开构建检查确认旧事件页为零。

## 新文案

公开成品与草稿统一称“帖子”；私有创作来源称“素材”。管理页的“记忆库”“记一笔”“我的记录”“首页精选”等入口改为创作空间、收录素材、我的素材、重点素材，不再暗示原始素材直接展示在首页。

空素材库可以直接新建帖子，不要求先导入资料。底层 entries/type=event 等兼容字段与技术路由暂保留，不代表旧事件仍是产品主体。

## 恢复注意

备份包含私人原文及账号校验数据，不能上传公开仓库。先停止网站并备份当前资料，再按对应备份中的恢复说明处理；不要直接覆盖日后新增的帖子。此次移出不清除 Git 历史中的历史提交，当前网站源文件与构建已去除旧内容。
