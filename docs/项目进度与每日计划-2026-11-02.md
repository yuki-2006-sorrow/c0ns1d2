# 项目进度与每日计划

入口：`/personal`（今天）、`/personal/plans`（计划）。沿用站主专属权限，手机凭证仍只能追加想法。

项目支持名称、状态、手动进度（允许未知）、关键日期、下一步和备注。下一步可以加入今天的任务。每日任务支持关联项目、选择日期、勾选/取消完成、改期；以前未完成的任务保留并提供移到今天操作。完成任务不会自动改变项目百分比。

数据保存在私人资料库 `personal.projects` 与 `personal.tasks`，不进入静态构建或 Git。本人提供的初始项目仅写入私有运行数据。旧的 profile、records 和 Siri 凭证继续保留。

写入沿用 revision 并发检查；冲突时保留表单，使用“读取最新进度”后检查并重试。任务完成记录完成时间。当前没有删除入口；可将项目暂缓或标记完成。

## DeepSeek 任务拆解

在“我 → AI 管家”填写本人 DeepSeek API Key；默认使用 deepseek-flash，可选择 deepseek-v4-pro。配置单独保存在被 Git 忽略的 `.local-collaboration/ai-config.json`，不回显、不进入文字导出。也支持 DEEPSEEK_API_KEY 环境变量；本机已保存配置优先。

项目卡片提供“AI 拆解”。仅发送选定项目的名称、进度、日期、下一步、备注和本次补充说明，不发送其他项目、日记、账户或手机凭证。请求只发往官方 https://api.deepseek.com/chat/completions，45秒超时，返回内容限制64KiB，校验JSON结构与步数。空回复、截断、错误结构、余额或鉴权失败均不创建任务。

步骤可修改、选择并指定日期，点击“加入每日计划”后才批量保存，来源标记 ai-reviewed。批次标识防止同一次重复提交；项目已改变时要求重新检查。AI 不自动改动项目百分比、关键日期或已有任务。

4327隔离预览使用明确标注的演示清单，不调用模型、不保存真实密钥。正式模型调用需要本人配置凭证；无凭证时不能声称已实测模型质量。

原共同创作、作品发布、素材库、成员注册与协作接口已从正式服务路由移除；旧网页链接转入私人空间，旧API返回410。历史数据与旧素材备份保留，没有删除个人记录、项目、手机凭证或账号数据。登录仅允许站主。个人文字导出只包含 personal 数据。

接口依据：[DeepSeek 调用说明](https://api-docs.deepseek.com/quick_start/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。
