# 作品为中心的共同创作档案

公开网站展示已发布作品；创作者从素材库获得灵感，在剪辑台编排作品。专题是作品的话题，不再充当小事件的公开列表。

## 视觉参考

- [Are.na](https://www.are.na/about)：参考收集、编排、连接、复用素材的工作方式；类型用于筛选，不作为独立入口。
- [Readymag Editorial](https://readymag.com/editorial)：参考长篇叙事、字体层级、图文节奏和视觉锚点。让成品拥有完整的阅读设计。
- [MUBI Notebook](https://mubi.com/en/notebook)：参考编辑选题与作品呈现。首页优先展示作品封面、题目、作者和导语。
- [Radiohead Public Library](https://www.radiohead.com/library/)：参考作品与档案的整体气质；本项目的原始档案仅供创作者访问。

统一极简方向：展厅、素材库、剪辑台与账号页共用 minimal-system.css，使用近白背景、炭黑文字、中性无衬线字体、细线和一致的按钮。去掉印章、渐变、彩色轨道、垂直标题及工具区深色皮肤，图像内容本身保留原色。参考 [Vitsœ](https://www.vitsoe.com/de/ueber-vitsoe/gutes-design) 的克制原则与 [Kinfolk Stories](https://www.kinfolk.com/stories/) 的内容呈现，具体规则为本项目的设计取舍。以上是本项目的设计取舍，不是对参考网站功能的逐项照搬。

## 数据和权限

1. **素材**：保留已有 entries、原始 ID、来源和历史。导入的 auto 聊天摘录映射为 chat 类型，不自动改写为新作品。其他类型包括经历、随笔、想法、观点、图片、视频和音频。
2. **作品草稿**：独立保存片段顺序、选取文字、说明、素材引用、协作者、版本与创作记录。引用修改不改动原素材。
3. **公开成品**：发布时保存一份独立快照。访客只得到快照中的选定文字和媒体，没有原始素材 ID、全文、来源路径、创作历史或协作者内部讨论。后续改草稿不会悄悄替换已发布成品。
4. **媒体**：公开成品通过作品专用媒体地址读取被采用的文件，原始媒体接口只对创作者开放；撤回成品后，作品媒体地址失效。
5. **协作**：作品发起人邀请创作者参与编排。保存使用 revision 校验，旧版本不能覆盖新版本；发起人或站主发布。保存历史和留言归属真实账号。目前采用共同保存与重新载入，尚非实时多人光标编辑。

素材库沿用原有记录范围：创作者资格是进入条件，不会把其他人的私人素材自动开放给全部创作者。旧版原始事件对访客开放的入口停止提供；公开内容以成品快照为准。

## 主路径

访客：作品展厅 → 阅读、观看或收听作品。

创作者：浏览素材 → 选取片段获得灵感 → 创建作品 → 编排、修改引用、添加串联 → 邀请共同创作 → 保存与发布。

后续完善：片段级音视频入点与出点、图片构图、版式模板、作品话题、素材导入预处理、实时协同。未经实现的能力不在界面中伪装成可用功能。
