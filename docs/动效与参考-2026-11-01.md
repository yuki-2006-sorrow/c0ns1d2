## 已加入

- 展厅标题、作品卡轻微淡入，前几张卡片错开 45ms，避免大量级联等待。
- 鼠标悬停封面时图片放大 1.5%，箭头移动 2px；仅精确指针设备启用。
- 新片段在画布和轨道以 240ms 淡入并上移 8px。
- 排序时根据片段原位置到新位置平移，约 240ms；正文输入不触发排序平移。
- 选中片段有短暂中性底色反馈。
- 协作面板打开时以 220ms 从右侧 20px 滑入，阅读/嵌入对话框以 180ms 进入。
- 手机素材/编排/片段切换时轻微淡入；操作提示淡入并在 4 秒后消失。
- 系统设置“减少动态效果”时，CSS 与脚本动效均停用；内容默认可见。

主要代码位于 `admin/minimal-system.css` 与 `admin/post-studio.js`。局部动画通过 Web Animations API 完成；不以循环动画、滚动劫持或整页重播作为浏览体验。
