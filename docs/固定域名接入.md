# c0ns1d2.com 固定入口

当前目标：先使用当前电脑提供共享后台，之后再迁移闲置主机。

## 地址分工

| 地址 | 用途 |
|---|---|
| `https://c0ns1d2.com` | 主站，绑定现有 Cloudflare Pages 项目 `c0ns1d2` |
| `https://www.c0ns1d2.com` | 可选的同站入口，也需在 Pages 自定义域中单独添加 |
| `https://c0ns1d2.pages.dev` | 原正式主站，继续可用 |
| `https://backend.c0ns1d2.com` | 固定 Cloudflare Tunnel 到当前电脑的 `http://127.0.0.1:4324` |

公网后台继续使用网站已有的登录、答题加入、访客和作者权限。原本机个人编辑器 `4323/admin` 不接入通道。新旧主站分别使用各自的登录 Cookie；不要预期一个域名的登录状态自动跨到另一个域名。

## 1. 域名 DNS

本次分配的 Cloudflare 名称服务器是 `marge.ns.cloudflare.com` 和 `steven.ns.cloudflare.com`。2026-10-30 已公开查询确认用户完成替换。接手时检查 Cloudflare 区域状态为 Active；名称服务器替换不等于网站绑定完成。

## 2. 将主站绑定 Pages

在与原网站相同的 Cloudflare 账号中进入：

Workers & Pages → `c0ns1d2` → Custom domains → Set up a domain → `c0ns1d2.com`。

按向导确认 DNS 和证书，等待 Active。需要 `www` 时重复添加 `www.c0ns1d2.com`。应通过 Pages 的向导添加，不仅是手工建立 CNAME。配置后验证主页、登录、访客、时间线和静态开场资源。

## 3. 授权本机官方通道工具

双击项目根目录的 `登录固定通道.bat`，在浏览器里选择 `c0ns1d2.com` 并完成官方授权。已有登录证书时不会覆盖它；按终端提示确认当前账号是否正确。

官方工具把登录证书保存在 Windows 用户目录 `.cloudflared/cert.pem`。受限代理环境可能无法创建该目录，需要用户在电脑上自行双击运行。证书由官方工具接收，不需要复制到聊天或仓库。

若浏览器授权成功、官方工具却因用户目录写入被拒而退出，可以由授权回传流程将证书保存到项目私有文件 `.local-collaboration/cloudflare-origin-cert.pem`。固定启动器优先读取此处，再查默认用户目录；该文件被Git忽略，不发布。2026-10-30已按此方式接收证书，后续不必重复登录；“登录固定通道.bat”检测到此文件时会直接提示使用启动器。

## 4. 创建及启动固定通道

完成授权后，双击 `启动固定通道.bat`。

启动器会查找或创建名为 `c0ns1d2-home` 的通道，将 `backend.c0ns1d2.com` 路由到它，并生成仅匹配该主机名、其他主机名返回404的本地配置。已有不同 DNS 记录不会被强行覆盖。与其他电脑的同名通道凭据不匹配时停止，避免误接。

凭据、运行配置和进程状态保存在被 Git 忽略的 `.local-collaboration/`，日志在被忽略的 `data-tools/`。后台进程隐藏运行；重复启动复用已确认身份的通道进程。

启动器检查本机服务根目录和进程身份后加载固定来源地址，实测公网 `/api/health` 正常才更新 `deployment/remote-origin.json`。若固定地址未连通，保留原发布配置，并尽量恢复原本机来源配置。不会改写真实账号、题目、记忆与附件；过程前后核对资料文件哈希。

启动器不安装系统服务、不自动设置开机启动、不购买云服务，也不会自行推送 Git。若修改了来源配置，会重启本机后台，已登录会话需要重新登录；请先完成正在进行的保存。

## 5. 发布并核验

固定通道健康检查通过后，将生成的 `deployment/remote-origin.json` 随兼容代码推送到原仓库，等 Pages 部署成功，再实测已绑定的主站地址；可选的www入口只有在Pages添加后才能使用。以后重启相同固定通道，域名不变，不需要因重启而修改或发布网站配置。

核验至少覆盖：匿名管理接口401、访客仅看开放记录、实际登录及自己的内容保存、图片权限、开场视频Range206、时间线，以及未绑定的预览域仍不可读档案。写入接口必须校验当前页面的同源来源，不能因为多个自有域名而允许跨域写入。

`关闭公网试用.bat` 可以停止当前已配置且身份匹配的通道，保留本机后台与资料；恢复固定通道使用 `启动固定通道.bat`。配置固定通道后，旧的临时通道启动器会提醒改用固定启动器。

电脑关机、休眠或断网时，动态内容仍不可用。固定地址不代表国内访问自动提速；腾讯云COS、CI、CDN等附加服务的额度和接入在另一项任务中核对，不由本流程自动启用。

参考：[Pages 自定义域](https://developers.cloudflare.com/pages/configuration/custom-domains/)、[Cloudflare 本地管理通道](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/local-management/create-local-tunnel/)。
