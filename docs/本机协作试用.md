# 统一后台与成员协作

## 开始和关闭

日常只用根目录两个入口：双击「启动.bat」启动网站，双击「关闭网站.bat」关闭本项目的公网通道和后台。已配置固定入口时，浏览地址为 https://c0ns1d2.com/ ；本机为 http://127.0.0.1:4324/ ，后台为 `/shared`。

初次建站从启动器打开的本机页面建立站主账号；已经建好的账号继续使用，不能重新初始化、替换真实题目或用测试账号覆盖正式资料。后台重启后需重新登录。

网站与后台使用同一份资料库。原来的个人编辑入口不再供日常使用，已有统一库时会拒绝启动旧编辑器。

## 编辑与整理

- 记忆、作品、想法统一在「记录与草稿」中编辑，支持 Ctrl/Cmd+S 保存。
- 站主的「资料整理」包含来源筛选、搜索、多选、批量回收和恢复，以及可嵌套的中事件分组、人物档案。
- 移入回收站前会列出所选记录；关联中的记录需先整理关联，或同时选择对应想法。保存时检查版本，过期批次整体拒绝，不会只处理一部分。
- 大事件、嵌套分组、参与人、作品类型与手动联想保留；列表介绍可留空，正文开头自动作为预览。
- 人物侧写和人格数值由站主管理，目前仅站主可阅读。分组名称修改保留原关联；已有参与人姓名作为关联键保持稳定，其他称呼填昵称。
- 保存后，前台直接读取新内容。日常编辑无需重新构建，也无需 push。

## 成员和分享

访问者回答站主设置的问题，达到通过条件后自动建立账号进入。账号与昵称由本人填写，尚未做实名或邮箱验证。问答控制新账号准入，不代替已有账号的密码。

- 阅读权限、投稿权限分别设置；「全部共同内容」不包含他人的私人或定向内容。
- 成员只能修改自己的原文，站主可以调整权限和下架记录，不能代改别人的原文。
- 作者可以选择仅自己、指定成员、共同内容，并决定是否发布。草稿不会向其他普通成员展示。
- 关联想法的两端也需有阅读权，才能看到这段关联。
- 站主可读取本机保存的全部内容，包括私人记录；成员加入时会看到并确认这一边界。

## 未登录访客

访客从 `/guest` 进入，只看站主明确开放且已发布的共同内容。私人、定向、草稿和人物档案不随其他记录一起开放。站主登录后点击「查看访客视角」仍按访客权限展示。

照片、视频和关联端点使用相同权限。撤销开放会关闭后续请求，已经被他人保存的副本无法撤回。成员修改已对访客开放的记录时，需要站主重新确认开放。

## 附件

支持 JPG、PNG、GIF、WebP、AVIF、MP4、WebM，单个文件不超过500MB。上传后还需保存记录，才会按分享范围开放。新附件在 `.local-collaboration/media/`，首次上传时建立此目录，不进入 public 发布目录。原有 `/photos/` 附件仍保留在 `public/photos/`，通过记录权限读取。

第一张照片用作封面；移除照片引用或把记录放回收站，不会永久删除照片文件。视频暂不自动转码，大视频可先制作播放副本。现有 HTTPS 外链仍依赖原服务，不能把外链当作本机私人存储。

## 迁移和备份

旧版资料库升级为统一格式时，先在 `.local-collaboration/backups/` 保存完整旧库，再加入人物、中事件分组和原话片段。保留原文、ID、修订版本、成员、题目校验材料、分享范围和访客标记。旧 Markdown 留作迁移恢复和模板构建，不再作为运行时资料读取或写入。

「导出文字资料」下载当前记录、人物和分组，不包含账号密码、题目答案或照片视频文件，不能代替完整恢复备份。

完整备份：先关闭网站，把 `.local-collaboration/`、`public/photos/` 与项目一起复制到另一块磁盘。恢复前先留存当前副本，关闭服务后恢复整套资料。资料库、通道凭据、题目校验材料与私人内容禁止上传公开仓库。旧 `.local-trash/` 保留作历史恢复，日常回收统一进入资料库。

## 公网和维护

当前固定后台为 `backend.c0ns1d2.com`，主站和原 pages.dev 入口读取同一资料。电脑、网络、后台和通道需要运行；固定地址不等于国内线路已经优化，也不等于已购买云空间。迁移与授权维护见[固定域名接入](固定域名接入.md)。

高级本机模式：`powershell -NoProfile -ExecutionPolicy Bypass -File admin/start-site.ps1 -LocalOnly`。仅关闭公网、保留本机后台可用 `admin/stop-site.ps1 -KeepLocal`。这些维护参数无需加入日常操作。

先运行 `npm run build`，再运行 `npm run test:collaboration`。设置 `CHECK_MAIN_BROWSER=1` 可用隔离账号运行完整桌面/手机回归，不修改真实资料。
