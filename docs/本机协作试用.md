# 本机协作试用

这是独立的协作预览。账号、准入规则、原文、分享对象和媒体保存在本机，不需要先购买云服务。

## 开始

1. 双击桌面项目里的「启动协作.bat」。
2. 首次从启动器打开的页面建立站主账号，密码至少12个字符。密码由你自行填写，不发给AI。
3. 在「管理」里填写实际题目、可接受答案（每行一个）、通过题数、默认阅读范围、投稿资格。
4. 创建完成后，本机首页为 http://127.0.0.1:4324/；登录、整理与管理入口为 http://127.0.0.1:4324/shared。
5. 站主可在「管理」调整账号权限、停用账号、重设成员密码、恢复回收站内容并查看最近操作。

首次建立站主时，会把原项目的记忆、作品、想法导入独立副本：原草稿仅站主可见；已公开记录作为共同内容。原有文件不会被改写。以后两套资料不会自动互相覆盖；协作预览的保存不会自动更新原本 pages.dev 网站。

「启动.bat」和4323仍是原本个人后台；「启动协作.bat」和4324是新协作试用入口。

## 成员与分享

- 访客回答题目并建立昵称、账号、密码；达到通过条件后自动进入，不逐份人工审核。
- 进入后仍受默认权限限制。默认「指定内容、不允许投稿」，站主可调整；「全部共同内容」不包含别人私人或定向分享的记录。
- 作者可以设为仅自己、指定成员、共同内容，并选择是否发布。草稿不会分享给其他普通成员。
- 普通成员只能修改自己的原文。有阅读权不等于有修改权；站主也不代写成员原文，可把违规记录移入回收站。
- 「从这里想到的」可以新建自己的想法，关联记忆或作品，也可以不关联。关联的端点必须同时有阅读权限，才能向其他成员展示这段关联想法。
- 站主作为本机资料管理者可以读取全部内容，包括私人记录。加入说明会明确展示此边界，并要求成员确认。
- 账号与昵称由本人填写，未做真实身份或邮箱验证；停用针对该账号。问答用于准入，不代替某个既有账号的密码。
- 事件的大/中/小层次字段保留；作品有书/电影/游戏类型。协作前台已接回原开场、精选卡片、列表、绳子时间线、阅读页及照片查看，按当前身份展示内容。桌面时间线支持拖动与缩放，手机保留纵向滚动。
- 在记忆或作品页可以直接写一点想法，先保存为自己的草稿，再去后台选择关联和分享对象；不要求预先想好标题。
- 原有人物侧写目前只供站主从参与人链接查看，未自动公开给成员或访客。

## 无需登录的访客通道

访客入口为 http://127.0.0.1:4324/guest。站主登录后进入「管理 → 访客通道 → 选择开放内容」，搜索并勾选希望公开的记录。只允许开放已发布的共同内容；旧资料默认全部不对访客开放。也可以在自己的编辑页勾选「同时开放给未登录访客」。

「查看访客视角」始终按未登录访客的权限展示，即使站主已经登录。照片、视频、时间线数据与关联想法同样遵守此范围；撤销开放会关闭后续请求，已经被别人保存的副本不能撤回。想法的关联端点必须先向访客开放；端点关闭时，关联想法也会从访客视图隐藏。

共同成员内容与匿名公开是两种不同的范围。只有站主能决定访客开放；成员修改一段已对访客开放的原文后，访客开放会自动取消，需站主重新确认。定向和私人内容不会因勾选其他记录而一起公开。

启动器在服务尚未运行时先构建前台。协作页面每次访问读取协作副本的新内容，日常保存不需要重新构建。服务重启后需重新登录，更新前先保存正在编辑的文字。开发时可在已构建后使用 `admin/start-collaboration.ps1 -NoBrowser -SkipBuild`。

## 照片和视频

支持JPG、PNG、GIF、WebP、AVIF、MP4、WebM。单个文件不超过500MB，上传过程中仍需保持连接；完成后保存记录才会按其分享范围开放。新文件在本机独立媒体目录，通过登录和权限检查读取，不进入public目录。

预留2TB指你自己的可用磁盘容量；程序不会自动购买或分配2TB云存储。视频不自动转码，播放兼容性取决于原编码；大于500MB的视频暂需先制作较小的播放副本。原有HTTPS外链图片仍然依赖原服务，不会因本机权限变为私人图片。

## 备份和恢复

资料位于项目根目录 .local-collaboration/。其中包含账号密码哈希、题目校验材料、历史原文、操作记录和媒体，已排除Git与网站构建。

关闭协作服务后，把整个文件夹复制到另一块磁盘备份。仅备份代码或archive.json不能备份照片与视频；只在同一磁盘复制一份也不能防硬盘故障。恢复时关闭服务，先保留当前副本，再恢复完整文件夹。服务重启后需重新登录。

原项目的「回收站」和协作预览的「回收站」彼此独立。协作回收站保留原文与附件，没有永久删除入口。历史版本可查看和复制回自己的编辑页保存。

## 临时公网试用

用户已选择先用无需域名的临时公网地址。运行「启动公网试用.bat」连接有权限检查的4324服务；原主站通过Pages转发接入。临时地址在重建通道时变化，电脑关机即无法访问。具体启动、关闭与主站地址更新见[公网试用](公网试用.md)。127.0.0.1仍仅供本机访问，不对外分享旧的无登录4323后台。

## 开发验证

先运行 npm run build，再运行 npm run test:collaboration，在临时副本验证准入、作者与定向权限、访客开放/撤销、原文/附件/关联端点边界、历史/回收站、会话撤销、请求来源及限速。正式协作资料不会被测试账号写入。

第一版采用单进程本地JSON资料库和原子替换保存，有进程锁，适合先验证40人小圈子的流程。2TB媒体独立流式写盘，不放入JSON。后续迁移可把记录、成员、权限和媒体一并迁入数据库/对象存储，不需要重写用户资料。
