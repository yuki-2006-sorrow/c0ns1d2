# DeepSeek 任务说明：事件正文精简 + 隐私识别

## 背景
这是一个个人记忆库网站。每个 `### EVENT` 是从微信群聊/私聊记录里聚类出的一个"事件"，
BODY 是该事件的原始对话（`**时间** 发言人：内容`）。请对每个事件做两件事：
1. 把原始对话压缩成一段可读的叙述；
2. 找出需要脱敏的隐私信息。

## 任务一：正文精简（summary）
- 用**第三人称**叙述这段对话发生了什么（主角是"我"，即记录主人朱浩宇；其他人用对话里的名字）。
- 保留：参与的人、发生了什么事、关键转折、情绪/氛围、有代表性的细节。
- 去掉：无意义语气词、重复确认、纯表情包、打招呼、"哈哈"等。
- 长度 **80–200 字**，一段连贯的话，不要分点。
- 另外挑 **1–3 句最有代表性或最有味道的对话原文**，放进 quotes（原样保留，含发言人）。

## 任务二：隐私识别（privacy）
逐个扫描 BODY，找出以下敏感信息，给出建议替换（替换成占位符）：

| type | 内容 | replacement |
|---|---|---|
| phone | 手机号（11位等） | [手机号] |
| idcard | 身份证号 | [身份证号] |
| wechat | 微信号/微信原始id | [微信号] |
| account | 银行卡号/各类账号 | [账号] |
| password | 密码/验证码 | [密码] |
| money | 转账/红包/收款的具体金额 | [金额] |
| link | 红包链接、内部链接、二维码 | [链接] |
| contact | 个人名片（推荐好友） | [名片] |
| address | 具体住址/门牌号/小区+楼栋 | [地址] |
| school | 班级群号/学号等 | [学号] |
| other | 其他可识别个人身份的信息 | [已隐藏] |

- 只记录**真正敏感**的；普通对话里的人名、学校名、地名不算隐私。
- 若该事件没有任何隐私，privacy 留空数组 `[]`。
- original 写 BODY 里出现的原文（可只写敏感片段），不要编造。

## 任务三：标题复核（可选）
若现有 TITLE 明显不准确、或和正文主题不符，给出一个更好的标题（"主题·细节"短语，10字内）；
若标题没问题，suggest_title 留空字符串 `""`。

## 输出格式（严格）
只输出一个 JSON 数组，不要输出解释、不要 markdown 代码块包裹。每个事件一个对象，
顺序与输入一致，覆盖输入里的**全部**事件：

```
[
  {
    "file": "dm-20240203-01-xxx.md",
    "suggest_title": "",
    "summary": "……一段叙述……",
    "quotes": ["发言人：原文……", "发言人：原文……"],
    "privacy": [
      {"type": "phone", "original": "13800000000", "replacement": "[手机号]"}
    ]
  }
]
```

## 注意
- JSON 必须合法：字符串里的换行用 `\n`，双引号用 `\"`，不要 trailing comma。
- 中文标点正常使用（·、，、。等）。
- 不确定算不算隐私时，宁可标出来（type 用 other）。
- 完成后把整个 JSON 保存为 `batch-XX.result.json`（XX 与输入批次号一致）。
